# Setup screen — proof

Proves [specs/ui/setup/index.md](../../../specs/ui/setup/index.md).

## Coverage model

A renderer contract covers the four authored states and the local connection handoff. It replaces the connection bridge and clipboard sink, proving what setup sends and renders, not IPC, authentication or the system clipboard. [Desktop product acceptance](../../product/desktop-app.md#^desktop-ac-connect-link) crosses the packaged page, preload, main process, server and served interface; [setup failure acceptance](../../product/desktop-app.md#^desktop-ac-setup-errors) proves inline recovery. The product success walk uses real CSS motion to observe Connected before navigation, without introducing an additional dwell requirement. The renderer contract controls animation frames and returns no active animations, covering the reduced-motion completion path without transition events; it forfeits real painting to that product walk.

The shared [Copy proof](../app/copy-button/index.md) owns clipboard success, fallback, confirmation and its timer for all callers. Setup proves the prompt supplied to that control and that copying does not advance or disable either step. The product connection walk includes native prompt selection before submission. Linux drag coverage observes native pointer hit testing, no move request and unchanged bounds. It forfeits native titlebar/compositor and frameless Mac movement; CSS properties alone are not movement evidence.

The card is static content using the frame's look. Its contract checks that it creates no artifact document or controls; setup requires no artifact runtime. Geometry, colours, Clouds styling and the reduced-motion CSS treatment stay with stylesheet delivery, UI conformance and review. The connection walk observes the normal-motion handoff; this proof orders no second Electron connection solely for the CSS preference. [Desktop asset delivery](../../arch/desktop/connect-flow.md#^desktop-t-local-assets) and [appearance](../../arch/desktop/appearance.md#^desktop-appearance-t-local) prove delivery and mode selection. General markup-comparison automation remains deferred under [TV-649](../../../specs/arch/ui/conformance.md#release-exception-for-tv-649); active stylesheet and functional evidence still applies.

## Test hooks

Electron assertions use the [user-data and version hooks](../../arch/desktop/connect-flow.md#test-hooks); the renderer contract supplies a recording local bridge at its dependency boundary, where production receives the packaged preload bridge.

The agent-link assertion uses the [external-open hook](../../arch/desktop/index.md#test-hooks), which records the URL in place of `shell.openExternal`.

The Copy dependency seam is declared by [the Copy proof](../app/copy-button/index.md#test-hooks); setup contracts may use its recording clipboard sink, forfeiting the clipboard to that proof.

## Assertions

- **Contract — states and submission.** Mount the production setup renderer in a mocked DOM with link/error fixtures and a recording bridge whose promises the test resolves or rejects. These mocks forfeit native submission and the real lifecycle to the product walks named above. Under [States](../../../specs/ui/setup/index.md#states) and [the frame](../../../specs/ui/setup/setup.frame), ready has the prompt and an empty, labeled, required link field; Copy requests standard size, the field `data-size="lg"`, and Connect `size="lg"`. Connecting disables the field and Connect and requests the spinner. Connected presents the check and Connected content with the steps inert. Error keeps the full link editable and connects its invalid marker to the supplied error paragraph in place of the hint. The card has its title but no artifact document, menu or navigation controls. At the [submission boundary](../../../specs/ui/setup/index.md#interaction), empty input submits nothing, a nonempty link can be submitted without copying first, and a failed attempt can be corrected and resubmitted; retry leaves the error treatment for the connecting state. With no active animations, the Connected handoff still completes after its animation frames without a transition event. *(covered by `packages/desktop/test/connect-page.test.ts` “renders ready, connecting, inline error and Connected through a single-link submission” and “completes the Connected handoff without transition events under reduced motion”)* ^setup-t-states
