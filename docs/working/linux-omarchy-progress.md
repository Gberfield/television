# Television Linux port progress

The port is reconstructed on upstream e81bfc74732d6c84af3d254d1ba2625838cbd1fb. Linux uses the shared Electron client with a native frame, session-selected Wayland/X11, Linux menu identity, a separate AppImage update adapter, portable/AppImage packaging and an Arch recipe. No maintained Linux update feed is configured.

The current setup, package, sandbox, connection, fixture, verification and review evidence is recorded in [Omarchy host acceptance](linux-host-acceptance.md). That record distinguishes production launch checks from test hooks and physical-input acceptance.

This is a local development branch. Upstream submission follows host acceptance and a later user request; no fork, push or PR is part of this continuation.
